## 1. 硬前置：移动中的 `stop` = `damped_hold`（**不在我的边界内，需授权**）

- 现状（事实）：`profiles/safety/quadruped_lab.yaml` 已有停止语义矩阵（`damped_hold` /
  `torque_zero_release` 并列），但**移动中取 `damped_hold` 尚未实现**，实际落到 `torque_zero_release`。
- 为什么是硬前置：机械臂交接互锁（L6）要求"狗 `speed == 0` 且姿态稳定"才允许放件；
  松力躺倒既不是 `speed == 0` 也不是稳定姿态 ⇒ 互锁无从谈起。
- 实现要点（提案）：`damped_hold` = 指令速度置零 + 按声明位置控制保持当前站立位形 + 计时至末速
  ≤ `stop.speed_tolerance_mps`（0.05 m/s）才报 SUCCEEDED；超时/越界 ⇒ 显式失败。
- **文件边界请求**：`src/iraf_adapters/unitree/{gait.py,unitree_go2.py}`、`src/iraf_skills/quadruped.py`、
  `tests/`。这三处与框架侧窗口重叠 ⇒ 请明确：(a) 授权我独占这些文件；或 (b) 由框架侧窗口实现、
  我只提供判据与验收场景；或 (c) 我先只写"停止语义矩阵 → 实现"的判据与负向用例（放 `tests/`）。
- 验收判据（建议）：移动中调 `stop` ⇒ 终态 `damped_hold`、末速 ≤ 0.05 m/s、倾角 ≤ 15°、
  看门狗未触发、安全事件 0；**负向**：移动中不得落到 `torque_zero_release`；
