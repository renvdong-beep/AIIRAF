# 00 执行规则（每轮先读本文件）—— 战役 `iraf-24h-2`

- 目标：让宇树 Go2 在 MuJoCo 里**能走、能转、能到点**（需求 2 第一阶段），并接入 S1 交互与实时观看。
- 机器台账（唯一权威）：`plans/iraf-24h-2/00-STATUS.json`；人工摘要：`00-日志.md`。
- 上游依据：`docs/adr/0008-quadruped-locomotion-and-navigation.md`（草案，本战役第 01 步定稿）、
  `.hermes/plans/2026-09-21_quadruped-locomotion-and-goto.md`（分步计划）。
- 已定硬约束（使用者确认，默认值）：最大线速度 **0.5 m/s**（保持现有声明）、**允许原地转弯**（vz 转向）。
  任何阈值/上限只来自声明；脚本与实现层不得写死。

## 1. 每轮执行算法（严格按序）

1. 读 `00-STATUS.json`，取状态不是 DONE/BLOCKED/DEFERRED 的**最小 id**；若为 `IN_PROGRESS`，
   先 `git status --short` 看盘上是否已有该步未提交产物：有则"复核 → 补 commit-plan → 提交 → 回写"，
   **不要重写已有代码**；没有才按步骤文件实现。
2. 读 `plans/iraf-24h-2/<id>-*.md`，按「步骤」用 file/terminal 工具真实执行。
3. 跑该步「验收」命令，原始输出落 `build/iraf-24h-2/<id>/`（已 gitignore，属证据区，不提交）。
4. 验收全过 → `git add` **只加该步「涉及文件」列出的路径**（契约同文交付可多带，但须在
   commit-plan.txt 与 note 里逐条说明）→ `git commit -F <预先写好的文件>`。
5. 回写：`00-STATUS.json` → `00-日志.md` 追加一行 → `build/iraf-24h-2/<id>/tick-report.md`（中文 ≤15 行）。
6. 每轮结束跑全量单测并记失败/错误数；基线（战役开始前）＝ `Ran 844 / failures=1 / errors=4 / skipped=4`。

## 2. 额度纪律（上一战役踩过，必须遵守）

- 顺序固定：**产物落盘 → 跑一条最关键验收 → 立刻提交 → 回写台账/日志/tick-report → 有余力再深挖**。
  绝不把"提交"留到最后：上一战役有整轮因工具额度耗尽被判 error（验收全绿但没提交）。
- 若察觉额度用掉大半而验收未全绿：立即收口，提交已完成部分并把状态置 `IN_PROGRESS`，note 写清下一步。

## 3. 硬规则（违反即本轮失败）

1. 安全铁律见 `AGENTS.md`；四足控制（步态/速度/转向）只走
   `TaskFlow → SkillRuntime → PolicyGateway → ControlAuthority → Provider → 适配器`，禁止旁路。
2. **能力只在验收通过后回填** `profiles/unitree_go2_mujoco.yaml` 的 capabilities；未验收即声明＝违规。
3. **停止语义不得混用**：移动中的 `stop` = `damped_hold`（减速到零并保持站立）；
   `torque_zero_release`（松力躺倒）只用于急停/安全事件。两者都要有正/负路径证据。
4. 声明自洽门禁：速度/加速度/角速度/位移/倾角/看门狗上限缺任一即失败；技能租约 TTL 必须 ≥ 声明时长
   （`profile_check --quadruped` 第 8 条已实现，改动后必须仍通过）。
5. 解释器一律 `/usr/bin/python3`（cron 默认 python3 是 Hermes venv，缺 mujoco/numpy/grpc，基线不可比）。
6. 逐位一致：重构步态/控制代码前后必须"快照 → 改 → 比对"，stand/stop 既有数字
   （高度均值 0.2801007638069918 m、stop 末速 0.003964950131491022 m/s、位移 0.00643820654999534 m、
   倾角 0.05779130222366524°）不得变化。
7. 只 add 自己负责的路径；禁止 `git stash/checkout/reset/add -A/add -f`；禁止 heredoc 提交。
   另一窗口可能改 `src/iraf_core/**`、`examples/demo3_arm/**`：**绝不触碰**，提交前 `git status` 确认。
8. 工作区冻结后才跑最终验收（验收脚本有脏工作区门禁）；证据里一律 `simulation=true`。
9. 不提交内网 IP；中文文档/注释/提交体；不推送远端；不创建新的 cron 任务。

## 4. 阻塞与延后

- 板卡/真机相关一律 `DEFERRED`（板卡不在场），不得用 dry-run/mock 冒充。
- 厂商控制器源码不在仓库（vendor 只锁 22 件模型）：步态必须自研参数化 trot（ADR-0008 决策 1）。
- ROS 2/Nav2/SLAM/避障/地形越障**不在本战役范围**；`navigate_to` 只承诺平面到点。
