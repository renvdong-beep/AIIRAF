# `damped_hold`（移动中停止）契约与验收场景

- 日期：2026-09-22
- 状态：**待实现**（本文只定契约与验收判据，不含实现；实现归属见 §6 的 D4）
- 依据：ADR-0008 决策 1（停止语义矩阵）、ADR-0009 §6.5、`profiles/safety/quadruped_lab.yaml`、
  铁律 1.2（先写契约与验收场景再写实现）、6.6（终态不得回写为成功）
- 为什么现在写：机械臂交接互锁（计划的 L6）要求"狗 `speed == 0` 且姿态稳定"才允许放件；
  现状移动中的 `stop` 落到 `torque_zero_release`（松力躺倒）⇒ **既不是 `speed == 0`，也不是稳定姿态**，
  互锁无从谈起。它是联动的**硬前置**。

## 1. 语义（写死）

`damped_hold` = **减速到零并保持站立**。不是松力、不是原地踏步、不是退出控制。

| 项 | 契约 |
|---|---|
| 控制源 | 停止期间**保持**控制权（单写者，经 `ControlAuthorityManager`；不得因停止而释放租约给别的控制源） |
| 速度 | 指令速度置零，并按声明的加速度上限（`max_accel_mps2 = 0.5`）减速 |
| 位形 | 保持当前站立位形（关节位置控制，姿态稳定），**不得**进入松力/自由落体 |
| 完成条件 | 末速 ≤ `stop.speed_tolerance_mps`（0.05 m/s）**且**倾角 ≤ `max_tilt_moving_deg`（15.0°）**且**机身高度在声明的站立容差内 |
| 超时 | 超过声明的停止超时仍不满足完成条件 ⇒ **显式失败**（不得报成功；不得静默继续减速） |
| 终态 | 只有满足完成条件才可报 `SUCCEEDED`；否则 `FAILED` 并带原因与最后状态 |
| 资源 | 停止后机体与足端资源仍由本执行占用（直到显式释放），安全事件时按铁律 9 进 `QUARANTINED` |

## 2. 何时用 `damped_hold` / 何时用 `torque_zero_release`

| 场景 | 语义 | 依据 |
|---|---|---|
| 移动中收到 `stop` | **`damped_hold`** | ADR-0008 决策 1 |
| 移动中 QP 无解/超时/解过期 | **`damped_hold`** | ADR-0009 §4.3/§6.5 |
| 站立态收到 `stop` | `torque_zero_release`（现状保留） | 既有验收（`build/acceptance/go2-skills`） |
| 急停 / 安全事件 | **`torque_zero_release`**（最高优先级） | 铁律 6.6 |

⇒ 两条语义**并列存在**，由「是否在移动」与「是否安全事件」共同决定；**不得互串**。

## 3. 正路径验收判据（每条都要数字 + 证据文件）

1. 移动中（`vx ≥ 0.2 m/s` 稳态）发出 `stop`：
   - 末速 ≤ **0.05 m/s**
   - 停止过程倾角 ≤ **15.0°**（`max_tilt_moving_deg`）
   - 停止后机身高度在站立容差内（对齐后名义 0.2884 m；容差按现有 stand 判据 `|z − 0.27| ≤ 0.02` 的口径换算）
   - 停止耗时 ≤ 声明的停止超时
   - 看门狗触发次数 = 0；安全事件 = 0
2. 停止后**保持 3 s 不漂移**：位置漂移 ≤ 声明的站立漂移上限（`max_base_translation_m = 0.05`）。
3. 终态 `SUCCEEDED`，且报告里含执行 id、控制源、Profile/Policy 版本（可追溯）。

## 4. 负路径（缺一不可，各要有独立用例与证据）

| # | 注入 | 期望 |
|---|---|---|
| N1 | 移动中调 `stop` | **不得**落到 `torque_zero_release`（终态必须 `damped_hold`） |
| N2 | 停止过程中 QP 无解/超时 | `damped_hold` 继续（按门禁），**不得**静默改用旧解、不得报成功 |
| N3 | 停止过程中解过期 > 2 个 MPC 周期（40.0 ms） | 同上（复用 `adapters/unitree/mpc/freshness.py` 的判定） |
| N4 | 停止过程中收到急停/安全事件 | 立即 `torque_zero_release`，终态 `FAILED`（不得回写成功） |
| N5 | 停止超时未达标 | 显式失败 + 原因 + 最后状态（末速/倾角/高度） |
| N6 | 另一控制源在停止未完成时申请接管 | 按租约/fencing token **拒绝**（铁律 12） |
