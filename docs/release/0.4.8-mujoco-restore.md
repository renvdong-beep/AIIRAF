| 项 | 之前 | 现在 |

### 2. 三个机器人的 Provider 收口（x86 `.145`）

| Provider | 端口 | 状态 |
|---|---|---|
| `iraf/piper-pick` | 50052 | active |
| `iraf/ur5-pick` | 50053 | active |
| `iraf/handoff-lab`（joint） | 50054 | active（修复后） |

修复项：

1. **handoff_lab_joint 起不来的根因**：MJCF 的
   `<compiler meshdir="../../../vendor/unitree_go2/.../assets/">` 在安装目录下解析到
   `/opt/vendor/...` 不存在 ⇒ `Error opening file '../../../vendor/.../base_0.obj'`。
   - 现场热修：已装 XML 的 meshdir 改绝对路径，provider 起来；
   - **代码修复（0.4.8）**：安装器 `_stage_scene` 现在会把外置 `meshdir`/`texturedir`
     整棵拷进 `<version>/models/assets|textures` 并改写属性，安装物自包含。
2. **supervisor 拒绝板卡来源**：报 `控制面不接受来自 10.203.247.209 的请求`；
   已把该地址加入 `iraf-provider-supervisor` 的 `--allow-hosts`（连同 `.147/.112/127.0.0.1`）。
3. **provider token 缺失**：板卡 `/etc/iraf/provider.token` 不存在 ⇒ 每次 submit 都降级为计划；
   已按 `.145` 的 `runtime.secrets` 落地 600 文件（值不打印）。
4. **ur5 / handoff 未启动**：用户作用域 systemd 需带
   `XDG_RUNTIME_DIR=/run/user/1000 DBUS_SESSION_BUS_ADDRESS=unix:path=/run/user/1000/bus`
   才能 `systemctl --user start`；三个单元现已 active。

## 六、补丁（同日）：恢复详细 MCP 输出

- **症状**：0.4.8 在 AgentOS 里执行“进入机器人开发模式”只返回 1.9 KB 紧凑清单（0.4.5 起默认紧凑）。
- **修复**：`deploy/sdk/env/edge-intel.env.tmpl` 默认 `IRAF_MCP_VERBOSE=1`；板卡站点 env 同步设置并重启 MCP。
- **实测**：`iraf_robot_mode(action=enter)` 返回 **1,884 B → 4,734 B**，新增 `examples` / `intents` 全量字段。
- **可回退**：站点设 `IRAF_MCP_VERBOSE=0` 即回到紧凑模式（端侧小模型省 token）。
- **产物**：bundle 因模板变更重新生成（`8e0af6e1…`），wheel 不变（`7e8548d2…`）。


## 七、补丁（同日）：scenario 主机解析 / 狗别名 / supervisor 装配

- **症状**：chat 里“handoff_lab 联合演示”失败，`iraf_get_run` 返回 `error=链路失败`、`steps=[]`、`via=""`。
- **根因**：`iraf_run_scenario` 在未设 `IRAF_SUPERVISOR_URL` 时回落 SSH，
  默认主机写死 `10.203.247.121`（已下线），板卡也无免密 key。
- **修复**：
  1. 代码：优先用场景注册表 host 的 `control_url`，其次由 `endpoint` 推导 `http://<ip>:8770`；
     两者都没有时显式 `IRAF-SCENARIO-HOST-UNSET`，不再静默 SSH 旧机；
  2. 装配单模板补 `IRAF_SUPERVISOR_URL` / `IRAF_SUPERVISOR_TOKEN_FILE`；
  3. `joint-handoff` 别名补 `狗 / 机器狗 / 四足`（“让狗站起来”不再落 piper 默认场景）。
- **实测**（板卡 MCP）：
  - `iraf_run_scenario(stand_stop)` → SUCCEEDED，7.8 s，`via=supervisor`；
  - `iraf_run_scenario(nominal)` → 9/9 步 SUCCEEDED，100.1 s，`passed=true`（含 stand/dock/pick/place/unload）；
  - `infer`: `让狗站起来 → joint-handoff`、`机器狗停靠 → joint-handoff`。
- **产物**：bundle 重打为 `62c94583…`；wheel 不变 `7e8548d2…`。
- **仍未解决**：直接 `iraf_submit_task("go2站起来")` 仍会被拒——handoff provider 的
  `IRAF_PROFILE=profiles/piper_mujoco.yaml` 只声明 piper 能力；需要联合 profile（0.4.9）。
