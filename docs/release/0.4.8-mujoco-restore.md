## 一、0.4.8 做了什么

### 1. 恢复 MuJoCo 真实仿真（板卡 `.147`）

| 项 | 之前 | 现在 |
|---|---|---|
| `IRAF_PLAN_ONLY` | 1（只算端侧计划） | **0** |
| `IRAF_REPLAY_EVIDENCE` | 1（回放录制证据） | **0** |
| `IRAF_PLAN_FALLBACK` | 1（失败即降级计划） | **0**（失败显式报错，不伪装成功） |
| provider 端点 | `10.203.247.121`（已下线） | **`10.203.247.145`** |
| 注册表 | 指向旧机 | 重封签，`errors=[]` |

### 2. 三个机器人的 Provider 收口（x86 `.145`）

| Provider | 端口 | 状态 |
|---|---|---|
| `iraf/piper-pick` | 50052 | active |
| `iraf/ur5-pick` | 50053 | active |
| `iraf/handoff-lab`（joint） | 50054 | active（修复后） |

修复项：

1. **handoff_lab_joint 起不来的根因**：MJCF 的
   `<compiler meshdir="../../../vendor/unitree_go2/.../assets/">` 在安装目录下解析到
   `/opt/vendor/...` 不存在 ⇒ `Error opening file '../../../vendor/.../base_0.obj'`。
   - 现场热修：已装 XML 的 meshdir 改绝对路径，provider 起来；
   - **代码修复（0.4.8）**：安装器 `_stage_scene` 现在会把外置 `meshdir`/`texturedir`
     整棵拷进 `<version>/models/assets|textures` 并改写属性，安装物自包含。
2. **supervisor 拒绝板卡来源**：报 `控制面不接受来自 10.203.247.209 的请求`；
   已把该地址加入 `iraf-provider-supervisor` 的 `--allow-hosts`（连同 `.147/.112/127.0.0.1`）。
3. **provider token 缺失**：板卡 `/etc/iraf/provider.token` 不存在 ⇒ 每次 submit 都降级为计划；
   已按 `.145` 的 `runtime.secrets` 落地 600 文件（值不打印）。
4. **ur5 / handoff 未启动**：用户作用域 systemd 需带
   `XDG_RUNTIME_DIR=/run/user/1000 DBUS_SESSION_BUS_ADDRESS=unix:path=/run/user/1000/bus`
   才能 `systemctl --user start`；三个单元现已 active。

## 四、复现/回滚

```bash
# 构建
bash deploy/sdk/build_sdk.sh --target aarch64-manylinux_2_28-cp311
bash deploy/sdk/build_sdk.sh --verify

# 板卡恢复真实仿真
sed -i 's/^IRAF_PLAN_ONLY=.*/IRAF_PLAN_ONLY=0/; s/^IRAF_REPLAY_EVIDENCE=.*/IRAF_REPLAY_EVIDENCE=0/; s/^IRAF_PLAN_FALLBACK=.*/IRAF_PLAN_FALLBACK=0/' /etc/iraf/edge-intel.env
systemctl restart iraf-mcp-http

# 回滚到计划/回放模式
sed -i 's/^IRAF_PLAN_ONLY=.*/IRAF_PLAN_ONLY=1/; s/^IRAF_REPLAY_EVIDENCE=.*/IRAF_REPLAY_EVIDENCE=1/' /etc/iraf/edge-intel.env
```

## 五、遗留

1. 现场 handoff XML 是**绝对路径热修**；下次用 0.4.8 产物重装后才会变成自包含的
   `<version>/models/assets/`（installer 修复已进包）。
2. `--allow-hosts` 目前是 `.147/.112/127.0.0.1/.209` 枚举；板卡换网段后需同步更新。
3. 板卡 `IRAF_PROVIDER_TOKEN_FILE=/etc/iraf/provider.token` 属站点凭据，安装器不生成，
   需部署时落地（本次手工从 `.145` 同步）。
