## 三、部署

**板卡（aarch64，0.4.7）**：

```bash
# 受控重装（保留 /etc/iraf 站点键与 scenes/providers）
mv /opt/iraf-sdk/0.4.7 /root/iraf-0.4.7-prev 2>/dev/null || true
for u in /etc/systemd/system/iraf-*.service; do mv "$u" /root/units-prev/; done
systemctl daemon-reload
bash deploy/sdk/install-iraf.sh --profile edge-intel \
  --sdk-wheel build/sdk/iraf_sdk-0.4.7-py3-none-any.whl \
  --runtime-bundle build/sdk/iraf-runtime-0.4.7-universal.tar.gz \
  --wheelhouse <wheelhouse目录> --allow-unverified
```

**x86 仿真机（`.145`，sim-x86）**：同一份 wheel + bundle，`--profile sim-x86`。

**Web 演示**：`deploy/demo/` 下 8084（AgentOS 对话展示）与 8085（机器人展示页）由 demo_api 驱动；`demo_viewer.html` 为展示页，8085 无机器人时轮询 job。

## 四、版本线说明

- 本仓库存在两条线：`main` 已到 **v0.5.1**（多场景 MCP 端点 0.5.x 线）；本分支 `release/0.4.2` 是板卡/演示线。
- 本次 Web 演示固化在 0.4.x 线上取 **0.4.7**，避免与 main 的 0.5.1 冲突；若要把演示能力并入 main，应按 0.5.2 处理（需合并/回归，另行评估）。

## 五、已知限制

- 演示页 8085 仅在 AgentOS job 触发后显示机器人画面，无机器人时保持空白并轮询（本轮修复）。
- `iraf_sdk` 为纯 Python wheel（`py3-none-any`），架构无关；runtime bundle 为源码，架构无关。
- wheelhouse 目前仅 aarch64（cp310/cp311）；x86 目标如需运行期依赖，需先抓 `x86_64` wheelhouse。
