## 这是什么

`0.4.2 = 0.4.1 + 演示期加固（server.py 4 处、+164 行）`，用于**冻结"能复现 1–4 步演示"的运行时**，作为控制面单点化改造（`plans/iraf-single-controlplane/`）的回滚基线。

## 与 0.4.1 的差异（仅 `src/iraf_adapters/mcp/server.py`）

| # | 新增 | 作用 |
|---|---|---|
| 1 | `iraf://examples/handoff_lab` 资源 | 联合世界演示入口与判据（只读资源，`hints.HANDOFF_LAB_EXAMPLE`） |
| 2 | `_ensure_scene(scene)` | 提交前自检 Provider 端口；不通则自动切换（冷启动实测 1.6s） |
| 3 | `_reject_foreign_host()` | endpoint 主机白名单；越界返回 `IRAF-PROVIDER-HOST-REJECTED`（不发起连接） |
| 4 | `iraf_switch_scene(scene)` / `iraf_run_scenario(scenario, display, hold_s)` | 显式场景切换；handoff_lab 全量 9 步一次调用（返回 `passed + steps[]`） |
