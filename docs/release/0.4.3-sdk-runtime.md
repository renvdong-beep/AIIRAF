## 4. 构建期警告（既有现象，非本次引入）

1. **本机 proto 导入探针不通过**：本机 `protoc 3.12.4` 生成的 `_pb2.py` 与已装 protobuf 版本不兼容（需 ≥3.19 生成）；构建使用仓库内 **prebuilt stub**（`build/generated/python`，manifest 记为 `provenance=prebuilt`）。
2. **本机无 `grpc_python_plugin`**：`*_pb2_grpc.py` 无法在本机复现，按原样登记（同样 prebuilt）。

两者都是 0.4.1 起就存在的构建设置，不影响目标端运行（目标端用 prebuilt stub）。

## 5. 部署（目标端 aarch64 板卡）

```bash
# 板卡侧（root）：把 build/sdk/iraf-runtime-0.4.3-aarch64.tar.gz 与 manifest/sha256sums 一起拷过去
sha256sum -c sha256sums.txt                 # 先校验
bash deploy/sdk/board_deploy.sh             # 既有部署入口（安装 + 预检 + 健康检查）
# 或按设计走 install.sh（安装 <prefix>/<version> + current 链接，切换与回滚只动链接）
```

- 回滚：`/opt/iraf-sdk/current` 指回旧版本目录即可（安装脚本按 `iraf-install-files.json` 只删自己装过的文件）。
