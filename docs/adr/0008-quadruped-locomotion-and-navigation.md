# ADR-0008：四足移动（行走/转弯）与到点导航的能力边界

**状态**：草案（待确认；本 ADR 未定稿前不得声明 `locomote` / `navigate_to` 能力）
**日期**：2026-09-21
**适用**：宇树 Go2 EDU（首期唯一四足本体，铁律 6.8）；仿真 `simulation: true`，真机需另行 HIL 验收
**关联**：ADR-0004（Go2 EDU 选型）、ADR-0007（场景交互范围）、`profiles/safety/quadruped_lab.yaml`（已预留速度/空间/倾角上限）、`AGENTS.md` 1.13 / 2.12 / 6.8

## 1. 决策

1. **步态控制源**：自研**参数化对角小跑（trot）控制器**，作为独立 Provider（`iraf_skills.quadruped`），
   参数（步频、步高、占空比、相位、支撑/摆动相、机身高度、PD 增益、力矩上限来源）**全部来自声明**；
   **不**引入 `unitree_sdk2` 的高层运动服务，也**不**使用学习策略（首期）。
   理由：仓库内只有厂商模型资产（`vendor/unitree_go2` 锁的是 22 件模型，不含控制器源码）；
   自研参数化 trot 的每一条物理假设都可声明、可复算、可负向测试。
2. **能力拆分**：`locomote`（速度指令 vx/vy/wz + duration_ms）与 `navigate_to`（目标位姿 x/y/yaw + 容差）
   都经 `TaskFlow → SkillRuntime → PolicyGateway → ControlAuthority → Provider → 适配器`；
   `navigate_to` 的**外环**（位姿闭环）与 `locomote` 的**内环**（速度跟踪）共用同一控制源，
   由 `ControlAuthorityManager` 保证单写者，禁止两个 Provider 同时写控制通道（铁律 1.13 / 2.13）。
3. **停止语义矩阵**（必须显式区分，禁止混用）：
   | 语义 | 取值 | 适用 | 后果 |
   |---|---|---|---|
   | 受控停止 | `damped_hold`（减速到零并保持站立） | 行走/转弯中的 `stop`、看门狗、到达终点 | 保持可控、可继续 |
   | 失能停机 | `torque_zero_release`（松力） | 急停、安全事件、显式"失能"请求 | 力矩型执行器松力后躺倒（已在报告中显式记录） |
   默认 `stop` 在**移动中**取 `damped_hold`；`torque_zero_release` 仅在急停/安全事件路径使用。
4. **不做**：ROS 2/Nav2 导航栈、SLAM、地形越障、动态避障、人形运动。首期只做**平面直线/原地转弯/到点**。

## 2. 必须声明的安全边界（缺声明即失败，不允许默认值）

| 项 | 现状 | 本 ADR 需补充 |
|---|---|---|
| `max_speed_mps` | 已声明 0.5 | 保留；补 `max_accel_mps2` 与 `max_jerk`（或声明"阶跃指令由速度斜坡实现"） |
| `max_yaw_rate_rad_s` | 已声明 1.0 | 保留；补是否允许原地转弯（`allow_in_place_turn`）与最小转弯半径 |
| `max_base_translation_m` / `max_tilt_deg` | 已声明 0.05 / 10°（站立语义） | 移动语义需**另立字段**：允许位移范围（工作空间矩形）与移动中倾角上限（建议 ≤ 15°）、跌倒检测阈值 |
| 看门狗与失联 | 未声明 | 控制器心跳超时 ⇒ `damped_hold`；状态过期 ⇒ 拒绝新指令 |
| 资源互锁 | 未声明 | 移动中禁止切换控制源；机械臂作业期间狗必须 `speed == 0` 且姿态稳定（为二期两臂一狗交接预留） |

## 3. 验收门禁（数值口径，全部来自声明；未达标即 FAILED，不放宽）

| 阶段 | 判据 | 建议阈值 |
|---|---|---|
| S1 原地踏步 | 四腿接触序列正确、机身高度波动、持续时长无跌倒 | 10 s 无跌倒；高度波动 ≤ 声明值 |
| S2 定速直行 | 平均速度误差、横向漂移、航向偏差 | 误差 ≤ 10%；漂移 ≤ 0.10 m / 2 m 行程 |
| S3 定速转弯 | 角速度误差、转弯半径误差 | 误差 ≤ 10%；半径误差 ≤ 声明值 |
| S4 到点 `navigate_to` | 位置误差、航向误差、末速、期间安全事件 | ≤ 0.10 m；≤ 5°；末速 ≈ 0（≤ 0.05 m/s）；安全事件 = 0 |
| 负向（每条都要有证据） | 超速指令、越界目标点、看门狗超时、无租约调用、终态执行复用 fencing token | 全部被拒并给出错误码 |

## 4. 后果与风险

- 步态控制是本项目迄今最难的一段：接触序列、摩擦与力矩饱和对参数敏感；预期迭代多，
  **不得**用"看起来在动"当验收，必须用上表数值。
- 自研 trot ≠ 厂商运动服务：不许宣称"导航/避障可用"，只承诺"平面定速移动 + 到点"。
- 真机不可用性：真机需 `unitree_sdk2` + HIL 验收（另立 ADR/证据），本 ADR 的结论仅适用 `simulation: true`。
