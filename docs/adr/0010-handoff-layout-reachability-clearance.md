# ADR-0010：交接布局的「可达性-净空」联合约束

- 状态：已接受（2026-10-12，代码规范化轮次 P8）
- 关联：`docs/debug/2026-09-24-joint-model-dog-arm.md` §11.95；提交 `eed6803`（A2 派生）、
  `a36069d`（A3 交叉校验）、`39ce14a`（D1 可达性判据固化）
- 决策者：IRAF 联合演示（2 臂 + Go2）维护者

## 背景（为什么需要这份 ADR）

`handoff_lab` 的「A 臂装货 → 狗搬运 → B 臂卸货」布局里，**站位、臂基座、放置航点**
三者共享同一个窄窗口：

- **可达性**约束：单臂的工具点必须落在以 joint1 轴为心的可达球内。架高布置实测
  需求 = `√(dy² + dz²)`，其中 `dy` = 目标距基座的水平距离、`dz` = 目标相对 joint1 轴的
  竖向高度（= 承载面高度 + 抬升量）。对 UR5e 基线，可达半径 ≈ 0.85 m
  （厂商 + 架高后的等效值，见下表）。
- **净空**约束：放置段腕部本体不得与载体（Go2躯干/髋/托盘）接触，判据 = 臂↔载体
  全部接触对的**有符号净空 ≥ 停靠容差**（0.030 m）。

2026-10-08 的实测结论：把 B 站**单独**挪 −y 0.24 m 虽能把净空从 −0.056840 m 拉到
+0.099247 m，但抓取侧 home 相位在 `dy = 0.69` 时**不可达**（IK 残差 0.024677363 m）；
而可行窗口（`dy ≤ 0.565`）内净空只有 +0.022524 m < 0.030 ⇒ **单动站位不成立**。

## 决策（约束的公式化）

单臂架高布置的可达边界是一条**只依赖两个量**的不等式，固化为纯函数
`iraf_core.kinematics.horizontal_reach_ok(horizontal_m, vertical_m, reach_m)`
（P7 / D1，2026-10-12）：

```
可达 ⇔  √(dy² + dz²) ≤ reach
净空 ⇔  min over (臂 geom, 载体 geom) pairs of signed_dist ≥ 停靠容差(0.030 m)
```

两者必须**联合求解**（任一单独动都撞墙）：

| 可调量 | 声明位置 | 影响 |
|---|---|---|
| 臂基座位置 | `robots[].placement.pos_m` | 同时改变"可达"与"净空" |
| home 抬升 | `robots[].reference_solver.baseline_overrides.grasp.home_rise_m` | 降低可放宽可达边界 |
| 站位 y / 放置朝向 | `frames[].handoff_station_frame*` / `grasp.place_approach_direction` | 移动净空窗口 |

## 实测数据（与 §11.95 一致）

可达性扫描（UR5e，reach ≈ 0.85 m，dz = 0.635 m）：

| dy (m) | √(dy²+dz²) | 可达 | 备注 |
|---|---|---|---|
| 0.45 | 0.778 | ✓ | 现值（余量 ~0.07 m） |
| 0.565 | 0.850 | ✓（边界） | 可达边界 |
| 0.69 | 0.940 | ✗ | 2026-10-08 被判不可达（残差 0.0247 m） |

净空扫描（`scripts/probe_place_carrier_dock_offset.py --scan`，载体按运行期实测
躯干高度 0.276627 m）：

| 站位 (x,y) | 最坏净空 (m) | 判定 |
|---|---|---|
| (0.450, 0.450) | −0.056840 | ✗（腕部侵入狗） |
| (0.450, 0.390) | −0.041536 | ✗ |
| (0.535, 0.245) | +0.026166 | ✗（< 0.030） |
| (0.563, 0.217) | +0.047943 | ✓ |
| (0.450, 0.210) | +0.099247 | ✓（但 `dy=0.69` ⇒ 不可达） |

## 后果

- **不再单动站位**：任何布局改动必须先用可达性判据 + 净空探针**扫出交集**再落声明。
- 抓取目标**从载体站位帧派生**（ADR 关联的 A2）：消除「站位帧 ↔ `target_override_world_m`
  同一事实两处手抄同改」的坑；同时声明两者时由构建期**交叉校验**拦下矛盾（A3）。
- 本约束只针对**仿真布局**；真机（S3/S4）因板卡不在场仍为 DEFERRED，不得据本 ADR
  推断真机可达性。
